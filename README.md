# Ibrakazah

## Избранные проекты

- **[Qorgan](https://github.com/Ibrakazah/qorgan)** — хакатонный MVP, который объясняет риск мошеннического перевода и моделирует его проверку. `Python` · `FastAPI` · `scikit-learn`
- **[MemeFace](https://github.com/Ibrakazah/admit)** — браузерная игра, в которой нужно повторять мимику и жесты. Кадры обрабатываются на устройстве. `TypeScript` · `React` · `MediaPipe`
- **[LOCUS](https://github.com/Ibrakazah/Locus_hackathon)** — хакатонный проект для абитуриентов Казахстана с подбором вузов и персональным планом поступления. `TypeScript` · `Next.js` · `Tailwind CSS`
- **[Aqbobek AI](https://github.com/Ibrakazah/AISHACKFINAL)** — прототип помощника для администрации школы с расписанием, голосовым вводом и обработкой заявок. `React` · `Vite` · `Python` · `FastAPI`
